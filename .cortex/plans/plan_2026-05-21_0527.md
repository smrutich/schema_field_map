### Implementation Steps

**File to create: `src/models/schemas.py`** (keep `__init__.py` for re-exports)

1. **Create `src/models/schemas.py`** with all 10 Pydantic models in dependency order:
   - `SourceField` — with `@computed_field` or `@model_validator` for `text_repr`
   - `DestinationField` — same `text_repr` pattern
   - `SemanticProfile` — simple model, no complex validators
   - `CandidateMatch` — with `model_validator(mode='after')` enforcing `hybrid_score = 0.8*emb + 0.2*lex`; `Literal["HIGH","MEDIUM","LOW"]` for confidence prior
   - `TableRoutingDecision` — confidence `Field(ge=0.0, le=1.0)`, reasoning `Field(min_length=5, max_length=200)`
   - `FieldMapping` — regex validator on `destination_field` (`^[A-Za-z_][A-Za-z0-9_.]*$` or None), regex on `type_transform` (`.+\s->\s.+`), confidence bounds, reasoning length
   - `TransformationRule` — `Literal` enum for `transform_type`
   - `TableMapping` — contains `List[FieldMapping]`, computed `confidence` as mean
   - `FinalOutput` — top-level with `datetime`, `List[TableMapping]`

2. **Update `src/models/__init__.py`** to re-export all models for clean imports

### Validation Rules (from spec)

| Field | Rule | How |
|---|---|---|
| `confidence` | 0.0–1.0 | `Field(ge=0.0, le=1.0)` |
| `reasoning` | 5–200 chars | `Field(min_length=5, max_length=200)` |
| `destination_field` | Regex or null | `field_validator` with regex |
| `type_transform` | `.+ -> .+` | `field_validator` with regex |
| `hybrid_score` | `0.8*emb + 0.2*lex` | `model_validator(mode='after')` |
| `unmapped_*` lists | Never null | `Field(default_factory=list)` |
| `generated_at` | ISO 8601 | `datetime` type |
